To install Brody AI in any fresh Unity project (Unity 2021.3+, 2022.3+, or Unity 6):

### Method 1: Unity Package Manager (Recommended)
1. In your Unity project, open **Window -> Package Manager**.
2. Click the + icon in the top-left toolbar.
3. Select **Add package from disk...**
4. Browse and select the package.json file in this directory.
5. Unity will import Brody AI and initialize automatically.

### Method 2: Direct Asset Import
Alternatively, copy the BrodyAI-Release folder directly into your project's Assets/ or Packages/com.decnet.brodyai/ folder.

### Launching Brody AI
- Click **Brody > Open Brody Chat** (or press Ctrl+Shift+B / Cmd+Shift+B).
- Click **Brody > Account & Settings > Cloud Sign In** to connect your account.
